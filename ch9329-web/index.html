04 / DEVICE

장치 정보 & 부팅 설정

장치
연결 후 설정을 읽어 주세요.

대상 PC에서 인식될 장치 종류를 선택하세요. 저장한 모드는 다음 전원 연결부터 적용됩니다. 최초 설정은 테스트 PC에서 마친 뒤 대상 PC에 연결하세요.

일반 USB HID 키보드만 인식합니다. 마우스·멀티미디어 키·사용자 정의 HID 기능은 제외됩니다.

최신 WCH 문서의 동작 모드 2는 키보드 + 마우스입니다. 구형 문서에는 설명 차이가 있으므로 제품 설명서의 모드 2 지원 여부를 먼저 확인하세요.

선택한 동작 모드를 소프트웨어 설정으로 저장합니다. 웹 연결에 필요한 시리얼 통신 모드는 프로토콜로 유지하며, 주소·속도·USB 식별 정보는 보존합니다.

저장 후 양쪽 USB를 모두 분리하고 다시 연결하세요. 웹 화면에서는 대상 PC의 USB 인터페이스 목록을 확인할 수 없습니다.

TRANSFER SPEED

케이블 전송 속도 올리기

기본 9600 bps가 전송 속도를 제한합니다. 장치에 새 속도를 저장한 뒤 전원을 다시 연결하면 더 빠르게 통신할 수 있습니다.

CH9329는 3.3V 동작 시 115200 bps를 지원하지 않습니다. 현재 동작·통신 모드 번호를 소프트웨어 설정으로 유지해 저장하며, HID 기능의 종류는 바꾸지 않습니다.

위쪽 “통신 속도”만 바꾸면 장치의 속도는 바뀌지 않습니다. 먼저 여기에서 저장하고 양쪽 USB를 모두 분리한 뒤 다시 연결하세요.

연결 도움말

제어 기기에는 CH340 쪽을, 대상 PC에는 CH9329 쪽만 연결합니다. 데스크톱은 CH340 시리얼 포트가 필요하며, 포트가 보이지 않으면 USB 연결 방향과 CH340 드라이버를 확인하세요.

안드로이드(갤럭시 등) Chrome은 드라이버 없이 USB 직접 방식으로 연결합니다. OTG 젠더로 CH340 쪽을 휴대폰에 꽂고, USB 사용 권한 요청을 허용하세요.

이 화면은 장치 응답을 받는 프로토콜 통신 모드가 필요합니다. 판매자가 ASCII 모드로 설정한 제품은 먼저 제조사 도구로 통신 모드를 바꿔야 합니다.
