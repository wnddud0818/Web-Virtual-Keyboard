이 브라우저는 Web Serial을 지원하지 않습니다. Chrome 또는 Edge를 사용해주세요. 펌웨어 설치는 HTTPS 또는 localhost에서만 사용할 수 있습니다.
현재 주소: ?
이 폴더에서 python3 -m http.server 8777 을 실행한 뒤 http://localhost:8777 로 여세요.

펌웨어는 브라우저에서 USB로 직접 전송됩니다. 별도 업로드는 없습니다.

장치가 보이지 않나요? BOOT 버튼을 누른 채 USB를 다시 연결한 뒤 버튼을 놓으세요.

빠른 시작

세 단계면 충분합니다.

설치 중에는 USB 케이블을 분리하지 마세요.
01연결

보드를 연결하세요

데이터 전송이 가능한 USB 케이블로 T-Dongle-S3를 컴퓨터에 연결합니다.

02설치

펌웨어를 설치하세요

위 버튼을 누른 뒤 목록에서 ESP32-S3 장치를 선택하고 설치를 진행합니다. 설치 대화상자는 영어로 표시됩니다.

03재연결

다시 연결하세요

완료되면 USB를 다시 연결하고, 화면에 표시된 IP로 웹 키보드를 엽니다.

설치 후

설치가 끝나면 웹 키보드가 준비됩니다.

설치가 끝나면 T-Dongle-S3가 자체 Wi-Fi(WVK-XXXX)를 띄웁니다. 화면에 표시된 비밀번호로 접속해 192.168.4.1을 열고, 사용할 Wi-Fi를 등록하세요. 이미 Wi-Fi가 등록된 기기라면 화면의 IP 주소로 바로 접속됩니다.
  • 웹에서 텍스트와 단축키 전송
  • WVK1 파일 전송과 CRC32 검증
  • 오프라인 decoder.html 설치
  • 전송 중지·재시도·진행률 표시
  • 자체 AP로 Wi-Fi 설정 (빌드 없이 변경)
