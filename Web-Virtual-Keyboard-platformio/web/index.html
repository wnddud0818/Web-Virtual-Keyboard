액세스 포인트 설정
액세스 포인트는 192.168.4.1에서 이 페이지를 제공합니다. 비밀번호는 장치 화면에 표시되며, 최소 8자 이상이어야 하고 개방형 액세스 포인트는 허용되지 않습니다.
저장하면 장치가 재부팅되므로 이 페이지의 연결이 끊깁니다. 선택한 네트워크로 다시 접속하세요. 액세스 포인트 모드라면 192.168.4.1의 장치 자체 네트워크입니다. BOOT 버튼을 3초간 누르고 있으면 언제든 액세스 포인트를 다시 띄울 수 있습니다.
